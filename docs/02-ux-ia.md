# 前端信息架构与页面设计

## 1. PC C 端

### 1.1 导航

推荐左侧栏：

- 概览
- 抖音账号
- 好友与火花
- 任务
- 发送记录
- 通知
- 设置

右上角：当前用户、权益状态/到期时间、帮助、退出。

当前 PC C 端 MVP 采用 `reference/tinyship-main/apps/tanstack-app` 的应用壳：
顶部 sticky 全局导航、窄内容容器和统一 Card 分区；Admin 仍可在后续阶段使用独立侧栏布局。
导航项在窄屏下保持单行横向滚动，避免压缩为不可读的多行菜单。

### 1.2 概览页 `/dashboard`

核心目标：用户 10 秒内知道“今天是否正常”。

内容：

- 已绑定账号数；
- 有效 / 过期 / 暂停账号数；
- 今日待发送 / 已成功 / 已失败；
- 下一次计划执行时间；
- 最近风险提示；
- 快速入口：绑定账号、同步好友、立即执行；
- 每个账号一张状态卡。

账号卡：

- 头像、昵称、抖音号；
- Session 状态；
- 启用任务数；
- 今日发送数；
- 最近一次同步；
- 下一次任务；
- “进入账号”按钮。

### 1.3 抖音账号页 `/accounts`

列表字段：

- 头像 / 昵称；
- 账号状态；
- 登录态；
- 已管理好友数；
- 今日发送；
- 风险状态；
- 最近检查时间。

操作：

- 添加账号；
- 重新登录；
- 检查登录态；
- 同步好友；
- 暂停所有任务；
- 解除绑定。

### 1.4 绑定账号流程 `/accounts/new`

MVP 仅 PC 扫码：

1. 创建 Binding Job；
2. 页面进入“二维码准备中”；
3. 后端返回二维码事件；
4. 用户抖音 App 扫码；
5. 页面显示“已扫码 / 等待确认 / 登录成功”；
6. 成功后创建 `DouyinAccount`；
7. 自动触发首次好友同步。

整个流程使用 SSE 或 WebSocket，不轮询大量 HTTP 接口。

### 1.5 账号详情 `/accounts/:id`

Tab：

- 概览
- 好友
- 任务
- 记录
- 登录与能力

“登录与能力”展示：

- 登录状态；
- Consumer Web 能力；
- Creator Web 能力；
- Protocol 能力；
- 上次验证时间；
- 最近错误。

### 1.6 好友与火花 `/friends`

筛选：账号、任务状态、火花状态、关键词。

表格：

- 头像；
- 备注/昵称；
- 抖音号；
- 火花天数；
- 是否已有会话；
- 火花维护开关；
- 今日状态；
- 最后发送；
- 操作。

好友的内部身份必须由 `platform_user_id` / `conversation_id` 驱动，前端不需要展示内部 ID。

批量操作只允许：

- 批量开启/关闭已有好友的维护；
- 批量设置时间窗口；

不提供任意好友批量私信入口。

当前 M2 页面已实现账号切换、昵称/抖音号搜索、火花状态与任务状态筛选、好友同步和单好友火花开关。
批量维护与时间窗口编辑留到任务配置模块，且仍需遵守上述批量操作边界。

### 1.7 任务页 `/tasks`

任务模型保持简单：

- 账号；
- 好友；
- 每日启用；
- 发送时间窗口；
- 文本或模板；
- 最近执行；
- 今日状态；
- 启停。

编辑抽屉：

- 时间窗口，例如 19:30–22:30；
- 内容；
- 是否允许首聊（高风险能力，默认关闭）；
- 保存。

当前 M3 页面已实现账号/好友任务列表、关键词与状态筛选、创建/编辑抽屉、每日启停和立即执行。
最近执行、今日状态等运行统计由 `/history` 模块提供；任务 API 当前只返回配置本身，不在任务页虚构执行结果。

### 1.8 发送记录 `/history`

字段：

- 时间；
- 账号；
- 好友；
- 任务；
- 通道；
- 状态；
- 错误码；
- 平台消息 ID（用户侧可隐藏）。

详情抽屉展示完整执行时间线：

`scheduled → started → adapter_selected → sent/failed`

### 1.9 通知 `/notifications`

通知优先级：

1. 账号登录失效；
2. 安全验证 / 限流；
3. 连续失败暂停；
4. 今日任务执行完成；
5. 系统维护。

### 1.10 权益与兑换 `/entitlement`

展示当前有效权益、到期时间、账号槽位、任务额度和功能列表，并提供卡密输入框。

页面只负责兑换授权，不出现价格、购买、订单、支付方式或退款入口。权益过期后，用户仍可进入系统查看历史和兑换新卡，但新绑定、任务启用与发送能力进入只读/暂停状态。

## 2. 微信小程序

小程序定位为“移动控制台”，而不是完整复制 PC。

### TabBar

- 首页
- 火花
- 记录
- 我的

### 2.1 首页

- 今日成功 / 待处理 / 失败；
- 账号状态卡；
- 下一次任务；
- 风险提醒；
- “立即执行”入口。

### 2.2 火花

按账号切换好友列表：

- 头像 + 昵称；
- 火花天数；
- 今日状态；
- 维护开关。

点击好友进入任务设置：

- 开关；
- 时间窗口；
- 消息内容；
- 最近发送记录。

### 2.3 记录

按日期展示：

- 成功；
- 失败；
- 跳过；
- 需要人工处理。

### 2.4 我的

- 账号与绑定信息；
- PC 端登录二维码/绑定码；
- 通知设置；
- 权益状态、到期时间与卡密兑换；
- 帮助与协议。

### 2.5 小程序登录

使用微信身份作为一个 `AuthIdentity`，不直接把微信 OpenID 当业务 User 主键。

首次进入：

- `wx.login()` 获取 code；
- 后端换取微信身份；
- 若未绑定产品账号，允许：
  - 新建用户；或
  - 输入 PC 端生成的一次性绑定码，将微信身份绑定到现有 User。

MVP 中抖音账号首次绑定仍推荐在 PC 完成。小程序对未绑定账号显示“请在 PC 完成首次绑定”。

## 3. PC 管理后台

建议独立应用 `/admin` 或独立域名，避免把管理员代码打进 C 端 bundle。

导航：

- 运营概览
- 用户
- 抖音账号
- 任务与发送
- 风险中心
- Worker / 队列
- Adapter / Capability
- 权益与卡密
- 站点设置
- 审计日志

### 3.1 运营概览

- DAU / 活跃用户；
- 有效账号数；
- 今日发送成功率；
- 失败码 Top；
- 风险账号数；
- Queue latency；
- Worker 在线数；
- Browser/Protocol 成功率。

### 3.2 用户管理

- 用户基础信息；
- 角色；
- 状态；
- 当前权益与有效期；
- 账号/任务额度使用情况；
- 最近登录；
- 授权时间线；
- 禁用/恢复；
- 审计记录。

管理员默认不可以查看抖音 Session 明文。

### 3.3 抖音账号管理

- 所属用户；
- 昵称；
- Session 状态；
- Risk 状态；
- Capability；
- 今日发送；
- 最近错误；
- 暂停/恢复。

### 3.4 Worker / 队列

- API/Worker 版本；
- Playwright Sidecar 版本；
- Protocol Sidecar 版本；
- 在线心跳；
- 队列长度；
- 运行中 Job；
- 失败 Job；
- Browser slot 使用情况。

### 3.5 Adapter 页面

展示的是“平台接入健康度”，不是内部 Cookie：

- `douyin.browser.consumer`: healthy/degraded/down
- `douyin.browser.creator`: healthy/degraded/down
- `douyin.protocol.im`: healthy/degraded/down

支持管理员临时关闭某个 Adapter，业务层自动选择其余可用能力。


### 3.5 权益与卡密

子页面：

- 权益方案；
- 卡密批次；
- 兑换记录；
- 用户授权。

卡密批次支持选择权益方案、有效天数、数量、兑换时间窗，生成后一次性导出明文。数据库只保存卡密 HMAC，不提供“找回原卡密”。管理员可以停用批次、撤销未使用卡密、为用户人工 Grant/Revoke，并且所有操作写审计日志。
