# 产品范围与版本边界

## 1. 产品定位

这是一个面向个人用户的“抖音火花维护与好友互动任务”产品，不把自己定位成营销工具或批量私信工具。

核心价值：

- 一个用户可以管理多个自己的抖音账号；
- 每个账号拥有完全隔离的登录态和好友数据；
- 用户从真实好友列表中选择需要维护的关系；
- 系统每天在用户设定的时间窗口执行一次互动；
- 任务失败、登录过期、触发安全验证时能够明确停止并通知用户；
- PC 负责完整配置，小程序负责随时查看和轻量操作。

## 2. 角色

### C 端用户

- 注册/登录产品账号；
- 绑定一个或多个抖音账号；
- 查看账号状态；
- 同步好友；
- 开启/关闭某个好友的火花维护；
- 配置消息内容、时间窗口；
- 手动执行一次；
- 查看发送记录、失败原因与风险提示；
- 在小程序中查看状态、启停任务、处理简单异常。

### 管理员

- 管理用户、角色与权益授权；
- 查看抖音账号运行状态；
- 查看任务队列、Worker、Sidecar 健康；
- 查看风险事件、失败率、Adapter 状态；
- 管理权益方案、卡密批次、兑换记录与人工授权；
- 查看安全审计日志。

## 3. MVP

### 必做

1. PC 用户注册/登录。
2. PC 扫码绑定抖音账号。
3. 多账号 Session 隔离与加密存储。
4. Session 状态检查。
5. 好友同步。
6. 好友稳定身份映射。
7. 为好友创建“每日一次”的火花任务。
8. 文本发送。
9. 用户自定义发送时间窗口。
10. 每日 Intent 幂等。
11. 手动立即执行。
12. 发送记录与失败原因。
13. 账号级互斥执行。
14. 限流/登录过期/安全验证时暂停。
15. 微信小程序：账号概览、好友任务启停、任务记录、风险提醒。
16. PC 管理后台：用户、账号、任务、Worker、风险、审计。
17. 卡密兑换与权益到期控制：系统内部不接入支付、订单或退款。

### MVP 不做

- 自动破解验证码或安全验证；
- 设备指纹伪装、验证码绕过等风控对抗；
- 群发营销；
- AI 自动生成大量私信；
- 完整聊天客户端；
- 自动回复机器人；
- 代理池/IP 轮换。

## 6. 产品边界

一个 Spark Task 表达的是：

> “在某个抖音账号下，对某个确定的好友，在每天某个时间窗口内，最多执行一次指定互动。”

它不是 Cron 表达式，也不是通用自动化 DAG。MVP 保持领域模型简单，避免重新做一个工作流平台。


## 7. 授权与商业边界

项目内部不接入在线支付系统，不维护价格、订单、支付单、退款、回调或支付渠道 SDK。

产品访问权限由 `EntitlementPlan + CardCode + EntitlementGrant` 控制：管理员生成卡密，用户在 PC 或微信小程序兑换，系统据此获得一段时间的账号槽位、任务额度与功能权限。

卡密如何在系统外获得不属于 Douyin Keeper 的领域模型。详见 `12-card-code-entitlement.md`。
