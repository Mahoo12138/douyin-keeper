# ADR 0001：以消息面板作为统一会话数据源

## 状态

已采用

## 背景

产品同时需要展示好友会话和群聊会话。此前好友来自粉丝列表抓取，群聊来自消息面板抓取，两条链路会造成数量、身份和平台路由不一致，也让任务依赖好友列表先完成。

## 决策

以抖音消息面板返回的会话快照作为唯一数据源。直接会话和群聊只保留为平台类型字段；两者都会在写入会话索引时生成任务所需的可发送目标投影。直接会话使用稳定平台用户标识，群聊使用稳定的平台会话标识生成内部投影键。

旧的好友同步接口保留为兼容入口，但内部转发到会话同步，不再调用粉丝/好友列表抓取。

## 结果

- 会话数量和展示名称来自同一条消息链路。
- 群聊不会因为没有好友关系而丢失。
- 直接会话和群聊统一进入火花维护，好友关系不是任务前置条件。
- 任务和发送记录暂时保留 `friend_id` 兼容字段，但发送时优先使用会话的 `platform_conversation_id` 路由。
