# M7 宝塔验收清单

对照 [`docs/02-M0-设计冻结/09-宝塔部署.md`](../../docs/02-M0-设计冻结/09-宝塔部署.md) 与路线图任务 12。勾完才能算 V1 可上线。

## 进程与网络

- [ ] 前端 Nginx 只开 80/443，root 指向 `spark/frontend/dist`
- [ ] API 监听 `127.0.0.1:8080`，Go 项目**不放行端口**
- [ ] Worker 独立进程（第二个 Go 项目或 Supervisor），不暴露公网
- [ ] Python Playwright / Node sidecar 仅本机，不放行
- [ ] MySQL、Redis 只绑 `127.0.0.1`，安全组不放行 3306/6379
- [ ] `/healthz`、`/readyz` 经 Nginx 反代；SSE `proxy_buffering off`

## 密钥

- [ ] `.env` 权限 640，属主 `www`，不进仓库、不进备份包
- [ ] `HUOHUA_SESSION_KEY` 与备份密钥 `BACKUP_KEY_FILE` **分存**
- [ ] 首次建超管后删掉 `HUOHUA_BOOTSTRAP_ADMIN_PASSWORD`

## 备份（宝塔计划任务）

每日一次，建议保留 7 日 + 异地一份：

```
0 3 * * * /bin/bash /www/wwwroot/huohua/spark/deploy/backup/backup.sh >> /www/backup/huohua/backup.log 2>&1
```

先准备：

```
mkdir -p /www/backup/huohua /www/backup/huohua-keys
openssl rand -base64 32 > /www/backup/huohua-keys/backup.key
chmod 600 /www/backup/huohua-keys/backup.key
```

- [ ] dump 含 `chat_messages`、`session_blob`、账本
- [ ] 同步 `var/media`（或 MinIO 桶）
- [ ] 备份文件权限 600，已加密
- [ ] 包内无 `.env` / `session.key`

## 恢复演练

抽一份 `huohua-*.tar.enc`：

```
BACKUP_FILE=/www/backup/huohua/最新.tar.enc \
  /bin/bash /www/wwwroot/huohua/spark/deploy/backup/restore-check.sh
```

- [ ] 用户余额合计一致
- [ ] 有效套餐行数一致
- [ ] 有效号位数一致
- [ ] `chat_messages` 条数一致

## 联调路径（真实数据，无假成功）

- [ ] 空库打开：看板/列表/折线均为空态，官网纸条无好友名
- [ ] 注册真实用户：1 个号位；体验天数按站点配置
- [ ] 管理员真实发卡或买月卡
- [ ] 加号共享同一套餐，无需再买月卡
- [ ] 已装 Chromium：`/douyin/:id` 扫码 Tab 显示 Worker 推来的真二维码；短信 Tab 能获取验证码并回填
- [ ] 未装 Chromium：失败提示 `playwright_missing` 或真实页面错误，不得假成功、不得写假好友
- [ ] 有真实归档后，`/admin/chat-review` 能搜到并产生 `admin.chat_read`

## 界面

- [ ] `/` 官网：痛点 + 功能 + 登录
- [ ] `/login` 独立页，无侧栏
- [ ] 用户进 `/dashboard`，管理员进 `/admin/dashboard`
- [ ] 看板不是大屏；不嵌官网、扫码、聊天正文
