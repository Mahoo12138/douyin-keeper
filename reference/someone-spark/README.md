# spark（业务根）

仓库根只放 `docs/` 与 `开源项目/`。业务代码都在本目录：

| 目录 | 内容 |
|---|---|
| `frontend/` | Vue 官网 + 控制台（`package.json`） |
| `backend/` | Go API / Worker / migrate（`go.mod`、`.env.example`） |
| `worker-py/` | Playwright sidecar 占位 |
| `protocol-node/` | Node 协议 sidecar 占位 |
| `deploy/` | 开发 Compose、宝塔 Nginx 样例 |

运行说明见仓库根 `README.md`。
